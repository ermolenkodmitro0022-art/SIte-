# Шахматный клуб "Шахісті"

Сайт для шахматного клуба с админ-панелью.

## Структура
* `index.html` - Главная страница
* `news.html` - Новости
* `tournaments.html` - Турниры
* `rules.html` - Правила
* `admin.html` - Админ-панель (Код доступа: **1502**)
* `style.css` - Стили

## Важное примечание по работе данных
В текущей версии сайта используется технология **localStorage**. 
Это означает, что все новости, турниры и изменения текста сохраняются **только в браузере того устройства, на котором они были добавлены**.

Если вы откроете сайт на другом компьютере или телефоне, он будет пустым (или со стандартными данными), пока вы не добавите данные и там.

## Как загрузить на Render (Инструкция)

1. **GitHub**:
   - Создайте репозиторий на GitHub.
   - Загрузите туда все файлы из этой папки.

2. **Render**:
   - Зарегистрируйтесь на [render.com](https://render.com).
   - Нажмите **New +** -> **Static Site**.
   - Подключите свой GitHub репозиторий.
   - В поле **Publish directory** (или Root directory) оставьте пустым или укажите `./` (точку и слеш).
   - Нажмите **Create Static Site**.

Сайт будет доступен по выданной ссылке.
